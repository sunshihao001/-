# 14｜门控阈值与 Downgrade：Trade Gate 如何只给 BLOCK / WATCH / PAPER_ONLY / NEED_MORE_DATA

## 这一篇要解决的问题

这篇服务于 `Skill 06：meme-trade-gate` 和 `Skill 07：meme-workflow-controller`。

Trade Gate 是研究流程的最后一道门。它输出的是当前阶段允许的状态，不是买卖建议。Phase 1 最高只允许 PAPER_ONLY。

## 正文

### 1. Gate 的作用

Trade Gate 读取 Evidence Chain 的结果，然后给出：

```text
BLOCK
WATCH
PAPER_ONLY
NEED_MORE_DATA
```

它不输出：

```text
BUY
SELL
AUTO_READY
SEMI_AUTO_READY
```

Phase 0 契约已经明确：SEMI_AUTO_READY 属于 Phase 4，AUTO_READY 属于 Phase 5。

### 2. BLOCK

BLOCK 表示研究流程不能继续推进。

典型原因：

- token 不存在
- 无池子或零流动性
- 高危权限风险
- 明确卖出限制证据
- 结构性 rug 风险过强
- 关键数据缺失且无法继续判断

### 3. WATCH

WATCH 表示可以继续观察，不进入纸面交易。

典型情况：

- 数据大体可读但结构不清晰
- 有若干风险但未形成强 blocker
- 证据链不足以支持 PAPER_ONLY
- token 太新，仍需等待更多行为数据

### 4. PAPER_ONLY

PAPER_ONLY 表示可以做纸面跟踪和复盘。

它需要：

- 基础安全风险没有明显 blocker
- 数据字段足够完整
- 钱包角色和结构证据没有强反证
- evidence chain 有支持证据和反证检查
- 仍然严格不触发真实交易

PAPER_ONLY 是学习和验证状态，不是交易许可。

### 5. NEED_MORE_DATA

NEED_MORE_DATA 表示关键字段不足。

常见原因：

- GMGN 返回字段缺失
- 持有人数据不足
- 钱包历史无法读取
- 池子数据过期
- evidence chain 缺少反证

### 6. Downgrade 逻辑

Downgrade 不是失败，它是防止系统过度自信的机制。

常见降级路径：

```text
PAPER_ONLY → WATCH
WATCH → NEED_MORE_DATA
NEED_MORE_DATA → BLOCK
```

也可能因为补齐数据从 NEED_MORE_DATA 回到 WATCH。

### 7. Workflow Controller 的职责

Controller 串联流程和状态，不替 skill 做业务判断。

它负责：

- 读取 phase_state.json
- 调用下一个 skill
- 记录 completed_phases
- 遇到 BLOCK 停止
- 遇到 ERROR 标记可重试
- 输出 workflow_summary.md

它不负责把 WATCH 改成 PAPER_ONLY，也不负责绕过某个 skill。

## 小结

- Gate 输出的是阶段许可，不是交易指令。
- BLOCK / WATCH / PAPER_ONLY / NEED_MORE_DATA 是 Phase 1 的安全上限。
- PAPER_ONLY 仍然不允许真实交易。
- Downgrade 是防止过度自信的核心机制。
- Controller 只调度，不替 skill 判断。
