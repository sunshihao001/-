# 09｜LP 机制与流动性深度：为什么“有池子”不等于“能安全退出”

## 这一篇要解决的问题

这篇服务于 `Skill 02：meme-token-panel` 和 `Skill 06：meme-trade-gate`。

Skill 01 只检查有没有池子和流动性。Skill 02 要进一步理解流动性的质量。Skill 06 要判断这些流动性证据是否足以支持 PAPER_ONLY 或必须 BLOCK / WATCH。

## 正文

### 1. AMM 池子的核心含义

AMM 池子提供交易对，例如 token/SOL。买卖价格由池子储备和交易规模决定。

池子存在说明可以观察交易环境，但退出体验取决于深度、滑点、储备结构、流动性稳定性。

字段反推四问：

- 量什么：量市场是否有可交易深度。
- 能伪：短期流动性、刷量成交、单侧注资都能制造表面活跃。
- 能算：liquidity、reserve、volume、price impact、pool age。
- 本质：流动性是退出条件，不是价值判断。

### 2. 深度和滑点

流动性规模越小，稍大的买卖就越容易造成价格大幅变化。meme token 经常出现“看起来涨很多，但卖不出去”的情况。

系统需要区分：

```text
有价格
有成交
有深度
能退出
```

这四件事不是同一件事。

### 3. LP 稳定性

流动性是否稳定，比某一时刻 liquidity 数字更重要。

需要关注：

- 池子创建时间
- 流动性是否刚注入
- 是否出现快速流出
- LP 是否由少数地址控制
- 成交是否主要来自少数钱包

### 4. 在系统中的位置

Skill 02 记录流动性事实。
Skill 04 可结合钱包结构判断 LP 控制风险。
Skill 05 汇总支持和反证。
Skill 06 决定 gate。

如果 liquidity 缺失或异常，应进入：

```text
missing_fields
downgrade_reasons
blocker_reasons
```

### 5. PAPER_ONLY 的边界

即使流动性看起来足够，Phase 1 也不能进入真实交易。

PAPER_ONLY 只代表：

```text
可以做纸面观察和复盘记录。
```

它不代表：

```text
可以真实下单。
```

## 小结

- 有池子只是可研究条件。
- 流动性深度决定退出质量。
- 流动性可能被短期制造。
- Trade gate 必须综合多项证据，不允许单靠 liquidity 给 PAPER_ONLY。
- Phase 1 的 PAPER_ONLY 仍然不是交易许可。
