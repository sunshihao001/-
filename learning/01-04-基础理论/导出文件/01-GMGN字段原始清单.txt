GMGN 字段原始清单 v1.0
==================================================
来源：GMGN gmgn-skills GitHub repo（2026-05-24 采集）
来源文件：
  - skills/gmgn-token/SKILL.md
  - skills/gmgn-market/SKILL.md
  - skills/gmgn-track/SKILL.md
  - GMGN 页面 Trending 截图
采集方式：从官方 API 文档提取，未调用真实 API
状态：字段研究阶段，不包含任何交易判断

边界声明：
  - 本文件只记录 GMGN 给了哪些字段
  - 不判断字段组合说明什么
  - 不判断 token 好坏
  - 不判断钱包结构
  - 不判断市场阶段
  - 不输出策略 / paper / 执行
  - 禁止 live / swap / private key / signing / broadcast
