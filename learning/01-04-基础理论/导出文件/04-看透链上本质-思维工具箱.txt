看透链上本质：思维工具箱准备清单
═══════════════════════════════════════════════════

核心前提：标签是别人的判断。行为规则是你自己的判断依据。
         依赖标签 = 依赖黑箱。依赖行为规则 = 你自己能看透。

═══════════════════════════════════════════════════
一、链上行为分析：6 个思维模型
═══════════════════════════════════════════════════

1. 首买时间窗分析 ✅可自己算
   核心问：池子创建后前 N 秒谁进了？
   方法：首买延迟 = swap_time - pool_create_time
   判断：< 2 秒 = 机器人或内部人
   场景：某 PUMP 币上线，前 5 笔买入全在 0.8 秒内完成，
         且这 5 个钱包之后在高点同步卖出 → 典型 INSIDER 矩阵
   数据源：RPC 拉 tx 按时间排序

2. 资金溯源树 ✅可自己算（但有限度）
   核心问：这些钱包的 SOL 从哪来？
   方法：从目标钱包反向遍历 SOL 转入记录，找共同父钱包，追 2-3 层
   场景：10 个「看似独立」的买入钱包，SOL 全从同一个 Binance 提款地址分发 → 同一庄家
   局限：聪明庄家用多层中转 + CEX 洗，追 3 层以上容易断链

3. 持仓集中度 / HHI 指数 ✅可自己算
   核心问：代币真的分散吗？
   方法：HHI = Σ(持仓占比²)，Top10 持仓占比
   场景：某币号称「社区币」，持仓者 2000+，但合并同源后 Top10 实控 68% → 假分散
   数据源：token accounts 快照 + 地址聚类

4. 卖出同步性检测 ✅可自己算
   核心问：这些钱包是不是同一个人/脚本？
   方法：多钱包卖出时间的标准差，< 3 秒大概率同控
   场景：5 个钱包在 2 秒内各卖出 3%，单看每个都不大，合计 15% 砸盘
   关键认知：时间戳不会骗人，同步性是最难伪装的特征

5. PnL 模式异常识别 ❌依赖平台
   核心问：谁在持续精准逃顶？
   方法：胜率 = 盈利交易数/总交易数，连续 10 币胜率 > 80% 且持仓 < 5 分钟 → 非人类
   场景：某钱包 30 天交易 50 次 meme，胜率 92%，平均持仓 3 分钟 → AGENT 或 INSIDER
   局限：自己算要遍历全部历史 swap，成本太高；平台数据可能漏算部分 tx

6. 买入金额分布指纹 ✅可自己算
   核心问：这些「不同钱包」的行为是不是太像了？
   方法：多钱包买入金额的变异系数，金额完全一致 → 脚本批量操作
   场景：20 个钱包各买入 0.5 SOL，精确到小数点后 9 位一样 → 批量伪装 ORGANIC

【最实用排序】首买时间窗 > 卖出同步性 > 资金溯源 > 持仓集中度 > 买入指纹 > PnL 异常

二、数学 / 统计计算模型
═══════════════════════════════════════════════════

1. HHI 赫芬达尔指数 [入门｜可手算]
   公式：HHI = Σ(持仓占比²)
   用法：> 0.25 = 高度集中 → 庄控盘
   配合基尼系数看分布不均程度，Gini > 0.9 在 meme 里是常态，
   但突然下降意味着派筹

2. Z-Score 突变检测 [中级｜需编程]
   公式：Z = (X - μ) / σ
   用法：对钱包转账金额/频率算 Z 值，|Z| > 2.5 标记异常
   输入：每笔 tx 的 from/to/amount/timestamp

3. EMA + 成交量加权偏离度 [中级｜需编程]
   公式：偏离度 = (Price - EMA) / σ
   用法：> 3σ 是极端拉盘信号
   配合自相关函数 (ACF) 检测买卖是否有周期性节奏 → 机器人特征

4. Pearson 相关系数 [入门｜可手算]
   用法：两个 meme 币价格序列的 r 值
   r > 0.8 说明同一资金盘在操作
   滞后相关：A 币涨后 B 币跟涨，时间差就是资金轮动节奏

5. 贝叶斯后验更新 [高级｜需编程]
   公式：P(Rug|行为) = P(行为|Rug)·P(Rug) / P(行为)
   用法：用历史 Rug Pull 案例训练先验，新币出现类似行为时实时更新跑路概率
   输入：钱包年龄、LP 锁定状态、持仓集中度等特征

6. 网络图分析 [高级｜需编程]
   PageRank：找资金网络中的核心节点（大庄）
   社区检测 (Louvain)：自动聚类关联钱包群
   输入：钱包间转账构建有向图，边权重 = 转账金额
   效果：表面 500 个地址实际是 3 个资金簇

【优先级】先上 HHI + Z-Score（半天搞定）→ 再加贝叶斯 + 网络图（需数据积累）
工具：Python numpy + networkx 覆盖全部计算

三、字段反推四问清单
═══════════════════════════════════════════════════

拿到任何字段，按顺序问：

  ① 量什么？原始数据源是什么（链上 tx / 区块 / 快照）→ 聚合方式（计数/求和/比率/排名）
  ② 能伪？输入端哪些行为可被批量制造
  ③ 能算？自己拿 RPC / 索引器能否复现，还是依赖平台私有标签库
  ④ 本质？它在度量哪种不对称性（信息 / 资金 / 时间）

【三字段反推示范】

  smart_money:
    ①量什么：被平台标记为高胜率的地址集合是否买入
    ②能伪：高度可伪。做市商可用历史高胜率钱包做入场表演
    ③能算：不可自算。你没有 GMGN 的地址标签库，标注逻辑不公开
    ④本质：信息不对称的二手判断。你在信任平台的信任

  rug_ratio:
    ①量什么：dev 历史发币中跑路占比
    ②能伪：部分可伪。dev 可换新钱包清零历史，但部署合约的链上记录不可删
    ③能算：可自算。Solscan 追 dev 地址 → 遍历其部署的 token → 检查流动性撤除事件
    ④本质：行为一致性检验，假设人会重复

  hot_level:
    ①量什么：单位时间内交互量 / 社交提及的综合热度
    ②能伪：极易伪造。批量小额买入刷 tx 数 + 机器人刷社交提及，成本极低
    ③能算：部分可算。链上 tx 频率可算，但社交数据源依赖平台爬虫
    ④本质：注意力代理指标，不是价值指标

═══════════════════════════════════════════════════
四、伪造检测铁律
═══════════════════════════════════════════════════

【不可伪造】
  • SOL 转账记录
  • 合约部署时间戳
  • LP 添加 / 撤除事件
  • 区块确认顺序

【可伪造】
  • 交易量（wash trade）
  • 持有人数（sybil 拆钱包）
  • 社交热度（bot 刷）
  • 「聪明钱」标签（用标记钱包做诱饵）

【判断口诀】
  链上状态变更不可伪
  链上行为模式可批量制造
  链下数据随便编

【自算 vs 依赖平台的判断标准】
  问自己：「如果 GMGN 明天关了，这个字段我还能产出吗？」
  能 → 核心指标
  不能 → 参考指标，永远不做唯一决策依据

═══════════════════════════════════════════════════
五、维特根斯坦的警告
═══════════════════════════════════════════════════

「看透本质」是一句伪命题。你把一个过程伪装成了一个终点。

链上可言说的：钱包年龄、持仓集中度、买卖时序——
  这些是规则，写下来就能用。

不可言说的：盘口的「气氛」、拉盘前的沉默——
  这些只能在交易中长出来，不能在准备中想出来。

陷阱：你以为存在一个「准备好了」的状态，然后才开始。
      没有这个状态。
      思维工具箱不是在书桌上装满的，是在战场上捡起来的。

判断标准：当你能对着一个币的数据说出「我不碰，因为 X 规则」——
         你就够了。
         不是看透本质，是能给出拒绝的理由。

做不到这一句话，再准备一万年也是拖延。

六、准备路径（建议顺序）
═══════════════════════════════════════════════════

  Phase 1：掌握 4 个核心行为模型（1-2 天）
    • 首买时间窗
    • 卖出同步性
    • 资金溯源（2 层）
    • 持仓集中度 HHI
    → 验收：能对一个真实 token 手动跑一遍

  Phase 2：掌握 2 个数学工具（1 天）
    • HHI 计算
    • Z-Score 异常检测
    → 验收：能用 Python 跑出结果并解读

  Phase 3：练习字段反推（和字段词典同步）
    • 对每个 GMGN 字段跑四问清单
    • 标记可自算 / 依赖平台 / 可伪造
    → 验收：词典里每个字段都有四问答案

  Phase 4：实战积累不可言说的部分
    • 对 10 个真实 token 做完整分析
    • 记录每次「感觉不对但说不清为什么」的时刻
    → 验收：无法量化，但做完你会知道

═══════════════════════════════════════════════════
局限性（诚实声明）
═══════════════════════════════════════════════════

  • 反推思维能帮你不被字段骗，但不能帮你靠字段赚钱
  • 链上数据有固有延迟，你看到时套利窗口可能已关
  • 最赚钱的信号往往不在公开字段里，而在你自己构建的私有指标中
  • 反推是防御工具，不是进攻武器
  • 资金溯源在实战中被高估——真正的大庄用 CEX 中转，追到交易所就断了
