# sol交易工作流os｜学习计划

## 学习目标

把 `Solana meme 交易工作流 OS` 学成一套可表达、可拆解、可实现、可验收的系统能力。完成后能清楚说出：这个 OS 的对象是什么、入口是什么、每一层做什么、为什么要先门控再执行、如何从 paper / review / semi-auto 概念逐步走向更严格的治理设计。

## 当前进度

- 当前文章：02
- 最近更新：2026-05-24
- 下一步：理解第一道门：风险过滤、归零风险、交易安全风险、证据缺口

## 学习路径

1. 先建立总图：Sol 交易工作流 OS 是一条状态化门控流水线。
2. 拆入口：GMGN 如何变成候选池，而不是买入信号。
3. 拆第一道门：归零风险与交易安全过滤。
4. 拆钱包结构：早期买入、同源钱包、资金路径、分发/出货。
5. 拆市场结构：启动、拉升、洗盘、二波、出货、死亡反抽。
6. 拆策略门控：REJECT / WATCH / TRACK / PAPER_REVIEW_CANDIDATE / MANUAL_REVIEW_REQUIRED / EXECUTION_BLOCKED。
7. 拆执行与风控边界：当前只到 paper-only / review，禁止 live / swap / private key / signing / broadcast。
8. 拆 Hermes 状态层：任务接续、回放、文件化状态、handoff。
9. 拆 MVP：第一版最小系统要做什么，不做什么。
