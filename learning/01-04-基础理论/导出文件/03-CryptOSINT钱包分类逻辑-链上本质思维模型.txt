CryptOSINT 钱包分类逻辑 — 看透链上本质的思维模型
═══════════════════════════════════════════════════

核心原则：不看标签，看行为。链上只有事实，没有身份。

一个钱包是不是庄家、是不是狙击手，不是谁贴的标签说了算，
是它在链上的行为模式决定的。

═══════════════════════════════════════════════════

5 类钱包的判定逻辑
───────────────────────────────────────────────────

1. INSIDER（庄家 / 内部人）

   判定规则：
   - 在代币创建后的区块 0-1 就进入
   - 且满足以下任一条件：
     a) 被 deployer（部署者）直接资助过 SOL
     b) 持有该代币供应量 > 1%

   链上本质：
   谁能在区块 0-1 就买入？只有提前知道这个代币要创建的人。
   谁会被 deployer 直接打钱？自己人。
   谁会在最早期就持有 >1% 供应量？预先安排好的钱包。

   这三个信号组合在一起，指向同一个结论：这个钱包和项目方有关系。

   实际标签格式：
   "FUNDED BY DEPLOYER" 或 "BLOCK 0 ENTRY — 3.2% SUPPLY"

───────────────────────────────────────────────────

2. AGENT（机器人）

   判定规则：
   - 交易间隔标准差 < 2 秒，且交易笔数 > 10
   - 或者与 Jito/MEV 程序有交互（程序地址硬编码）
   - 或者交易 > 20 笔且间隔标准差 < 5 秒

   链上本质：
   人手动交易不可能每笔间隔都精确到 2 秒以内。
   标准差极低 = 节奏极均匀 = 程序在执行。
   和 Jito tip / Jito bundle 程序交互 = 在用 MEV 基础设施。

   MEV 程序硬编码地址：
   - Jito tip: T1pyyaTNZsKv2WcRAB8oVnk93mLJw2XzjtVYqCsaHqt
   - Jito bundle: HFqU5x63VTqvQss8hp11i4bPYoTAYn4jQf4g3HcNBhiL

   实际标签格式：
   "MEV BOT — 15 TXS" 或 "BOT PATTERN — 1.3s STDDEV"

───────────────────────────────────────────────────

3. SNIPER（狙击手）

   判定规则：
   - 在区块 ≤ 3 进入
   - 且交易笔数 ≤ 2

   链上本质：
   极早进入（区块 3 以内）+ 极少交易（1-2 笔）= 精准打击。
   这种钱包不是在"发现机会"，是在"等待已知目标出现"。
   它提前知道这个代币要上线，设好了自动买入。
   买完就不动了，等拉盘后一次性卖出。

   和 INSIDER 的区别：
   INSIDER 可能持续参与（区块 0-1 + 多笔交易 + deployer 资金关系）
   SNIPER 是一锤子买卖（极早 + 极少交易 + 不一定有资金关系）

   实际标签格式：
   "BLOCK 2 SNIPE — 1 TX"

───────────────────────────────────────────────────

4. COPY（跟单者）

   判定规则：
   - 在区块 2-5 进入
   - 交易笔数 3-15
   - 跟单延迟检测：与某个 INSIDER/AGENT 的交易时间差在 3-30 秒
   - 延迟标准差 < 5 秒（跟得很稳定）
   - 至少匹配 ≥ 2 次（不是偶然）

   链上本质：
   跟单者不是庄家，但跟庄家有信息链接。
   它的交易总是比某个 INSIDER 晚几秒到几十秒。
   延迟稳定 = 用了跟单机器人或信息通道。
   多次匹配 = 不是巧合，是系统性跟随。

   实际标签格式：
   "BLOCK 3 ENTRY — FOLLOWS INSIDER PATTERN"

───────────────────────────────────────────────────

5. ORGANIC（有机用户 / 散户）

   判定规则：
   不满足以上任何条件。

   链上本质：
   进入时间不特别早，交易节奏不特别规律，
   没有和 deployer 的资金关系，没有 MEV 交互，
   没有明显的跟单模式。
   这是正常的市场参与者。

核心数据点（做判断需要的原始信息）
───────────────────────────────────────────────────

  address           — 钱包地址
  firstBlock        — 相对于代币创建的首次出现区块（不是绝对区块号）
  txCount           — 交易笔数
  txTimestamps[]    — 每笔交易的时间戳（用于算间隔标准差）
  totalBought       — 总买入量
  totalSold         — 总卖出量
  currentHolding    — 当前持有量
  supplyPercent     — 持有占总供应量百分比
  isFundedByDeployer — 是否被代币部署者直接转过 SOL
  interactsWithMev  — 是否和 Jito 等 MEV 程序交互过
  firstFunder       — 第一笔资金从哪个地址来
  walletAge         — 钱包创建时间距今多久

信誉评分（跨代币累积）
───────────────────────────────────────────────────

  基础分（按钱包类型）：
    INSIDER = 25 分
    AGENT   = 10 分
    SNIPER  = 8 分
    COPY    = 3 分
    ORGANIC = 0 分

  乘数因子：
    平均入场区块 < 2       → ×1.5（总是极早进入）
    钱包年龄 < 1 小时      → ×1.5（新钱包，专门创建的）
    资助了 > 3 个下游钱包  → ×1.2（资金分发节点）

  最终评级：
    CLEAN    (0-10)   — 干净
    LOW      (11-30)  — 低风险
    MODERATE (31-55)  — 中等风险
    HIGH     (56-80)  — 高风险
    EXTREME  (81-100) — 极高风险

  关键：这个分是跨代币累积的。
  一个钱包如果在多个代币里都是 INSIDER，分数会叠加。
  反复出现的庄家钱包，信誉分会越来越高。

═══════════════════════════════════════════════════

有机度评分（代币级别）
───────────────────────────────────────────────────

  organicScore = ORGANIC 钱包数 / 总钱包数 × 100

  < 20%  → CRITICAL — 价格行为基本是人为制造的
  < 40%  → HIGH     — 高度人为操控
  < 65%  → MEDIUM   — 有操控成分
  ≥ 65%  → LOW      — 相对有机

  这个指标的本质：
  如果一个代币 80% 的持有者都是 INSIDER + AGENT + SNIPER + COPY，
  那它的价格走势就不是市场行为，是安排好的。

思维模型总结：看透链上本质的 4 个问题
───────────────────────────────────────────────────

对任何一个钱包，问 4 个问题：

  1. 它什么时候进来的？
     区块 0-1 = 内部人。区块 ≤ 3 且只买一次 = 狙击手。

  2. 它的钱从哪来的？
     deployer 直接打的 = 自己人。新钱包 + 大额买入 = 专用钱包。

  3. 它的交易节奏像人还是像机器？
     间隔标准差 < 2 秒 = 机器。和 MEV 程序交互 = 机器。

  4. 它跟谁的节奏？
     总是比某个 INSIDER 晚 3-30 秒 = 跟单。多次匹配 = 系统性跟单。

  这 4 个问题不依赖任何平台标签。
  只需要链上时间戳、交易记录、资金流向。
  任何人都可以自己验证。

和 GMGN 标签的本质区别
───────────────────────────────────────────────────

  GMGN 说一个钱包是 smart_degen：
    → 你不知道为什么
    → 你不知道判定规则
    → 你不知道置信度
    → 你无法自己验证
    → 它可能对，也可能错，你没办法判断

  CryptOSINT 说一个钱包是 INSIDER：
    → 因为它在区块 0 进入
    → 因为 deployer 给它转了 2 SOL
    → 因为它持有 3.2% 的供应量
    → 你可以上链自己查
    → 每一条都可以验证或推翻

  标签是别人的判断。行为规则是你自己的判断依据。
  依赖标签 = 依赖别人的黑箱。
  依赖行为规则 = 你自己能看透。
