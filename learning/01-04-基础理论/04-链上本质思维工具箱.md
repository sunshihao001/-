## 正文

### 1. 六个链上行为分析模型

这些模型的共同特点：不依赖任何平台标签，只用链上事实。

**模型 1：首买时间窗分析** ✅可自己算

核心问题：池子创建后前 N 秒谁进了？

计算方法：`首买延迟 = swap_time - pool_create_time`

判断标准：< 2 秒基本是机器人或内部人。

场景：某 PUMP 币上线，前 5 笔买入全在 0.8 秒内完成，且这 5 个钱包之后在高点同步卖出。这就是典型的 INSIDER 矩阵。

**模型 2：资金溯源树** ✅可自己算（有限度）

核心问题：这些钱包的 SOL 从哪来？

计算方法：从目标钱包反向遍历 SOL 转入记录，找共同父钱包，追 2-3 层。

场景：10 个看似独立的买入钱包，SOL 全从同一个 Binance 提款地址分发。同一庄家。

局限：聪明庄家用多层中转 + CEX 洗，追 3 层以上容易断链。资金溯源在实战中被高估了。

**模型 3：持仓集中度 / HHI 指数** ✅可自己算

核心问题：代币真的分散吗？

计算方法：`HHI = Σ(持仓占比²)`，配合 Top10 持仓占比。

场景：某币号称社区币，持仓者 2000+，但用同源分析合并后 Top10 实控 68%。假分散。

**模型 4：卖出同步性检测** ✅可自己算

核心问题：这些钱包是不是同一个人 / 脚本？

计算方法：多钱包卖出时间的标准差，< 3 秒大概率同控。

场景：5 个钱包在 2 秒内各卖出 3%，单看每个都不大，合计 15% 砸盘。

关键认知：**时间戳不会骗人，同步性是最难伪装的特征。**

**模型 5：PnL 模式异常识别** ❌依赖平台

核心问题：谁在持续精准逃顶？

计算方法：`胜率 = 盈利交易数 / 总交易数`，连续 10 币胜率 > 80% 且持仓 < 5 分钟，非人类。

局限：自己算要遍历全部历史 swap，成本太高。平台数据可能漏算部分 tx。

**模型 6：买入金额分布指纹** ✅可自己算

核心问题：这些不同钱包的行为是不是太像了？

计算方法：多钱包买入金额的变异系数。金额完全一致（如都是 1.000 SOL，精确到小数后 9 位）说明是脚本批量操作。

**最实用排序：首买时间窗 > 卖出同步性 > 资金溯源 > 持仓集中度 > 买入指纹 > PnL 异常**

### 2. 六个数学 / 统计计算工具

**HHI 赫芬达尔指数** [入门｜可手算]

`HHI = Σ(持仓占比²)`。> 0.25 = 高度集中，庄控盘。配合基尼系数，Gini > 0.9 在 meme 里是常态，但突然下降意味着派筹。

**Z-Score 突变检测** [中级｜需编程]

`Z = (X - μ) / σ`。对钱包转账金额 / 频率算 Z 值，|Z| > 2.5 标记异常。

**EMA + 成交量加权偏离度** [中级｜需编程]

`偏离度 = (Price - EMA) / σ`。> 3σ 是极端拉盘信号。配合自相关函数 (ACF) 检测周期性节奏。

**Pearson 相关系数** [入门｜可手算]

两个 meme 币价格序列的 r 值。r > 0.8 说明同一资金盘在操作。滞后相关可以看资金轮动节奏。

**贝叶斯后验更新** [高级｜需编程]

`P(Rug|行为) = P(行为|Rug)·P(Rug) / P(行为)`。用历史 Rug Pull 案例训练先验，实时更新跑路概率。

**网络图分析** [高级｜需编程]

PageRank 找核心节点（大庄），Louvain 社区检测自动聚类关联钱包群。表面 500 个地址实际可能是 3 个资金簇。

优先级：先上 HHI + Z-Score（半天搞定），再加贝叶斯 + 网络图（需数据积累）。Python `numpy` + `networkx` 覆盖全部。

### 3. 字段反推四问清单

拿到任何字段，按顺序问：

```text
① 量什么？原始数据源是什么 → 聚合方式是什么
② 能伪？输入端哪些行为可被批量制造
③ 能算？自己拿 RPC / 索引器能否复现
④ 本质？它在度量哪种不对称性（信息 / 资金 / 时间）
```

用三个 GMGN 字段走一遍：

**smart_money**：
- ①量什么：被平台标记为高胜率的地址集合是否买入
- ②能伪：高度可伪。做市商可用历史高胜率钱包做入场表演
- ③能算：不可自算。你没有 GMGN 的地址标签库
- ④本质：信息不对称的二手判断。你在信任平台的信任

**rug_ratio**：
- ①量什么：dev 历史发币中跑路占比
- ②能伪：部分可伪。dev 可换新钱包清零历史，但部署合约的链上记录不可删
- ③能算：可自算。追 dev 地址 → 遍历其部署的 token → 检查流动性撤除事件
- ④本质：行为一致性检验，假设人会重复

**hot_level**：
- ①量什么：单位时间内交互量 / 社交提及的综合热度
- ②能伪：极易伪造。批量小额买入刷 tx 数 + 机器人刷社交
- ③能算：部分可算。链上 tx 频率可算，但社交数据依赖平台
- ④本质：注意力代理指标，不是价值指标

### 4. 伪造检测铁律

**不可伪造：**
- SOL 转账记录
- 合约部署时间戳
- LP 添加 / 撤除事件
- 区块确认顺序

**可伪造：**
- 交易量（wash trade）
- 持有人数（sybil 拆钱包）
- 社交热度（bot 刷）
- 「聪明钱」标签（用标记钱包做诱饵）

**判断口诀：链上状态变更不可伪，链上行为模式可批量制造，链下数据随便编。**

**自算 vs 依赖平台的判断标准：** 问自己「如果 GMGN 明天关了，这个字段我还能产出吗？」能 → 核心指标。不能 → 参考指标，永远不做唯一决策依据。

### 5. 准备路径

Phase 1：掌握 4 个核心行为模型（1-2 天）
- 首买时间窗、卖出同步性、资金溯源（2 层）、持仓集中度
- 验收：能对一个真实 token 手动跑一遍

Phase 2：掌握 2 个数学工具（1 天）
- HHI 计算、Z-Score 异常检测
- 验收：能用 Python 跑出结果并解读

Phase 3：字段反推（和字段词典同步）
- 对每个 GMGN 字段跑四问清单
- 验收：词典里每个字段都有四问答案

Phase 4：实战积累
- 对 10 个真实 token 做完整分析
- 记录每次「感觉不对但说不清为什么」的时刻
- 验收：无法量化，但做完你会知道

### 6. 维特根斯坦的警告

「看透本质」是一句伪命题。你把一个过程伪装成了一个终点。

链上可言说的——钱包年龄、持仓集中度、买卖时序——这些是规则，写下来就能用。不可言说的——盘口的气氛、拉盘前的沉默——这些只能在交易中长出来，不能在准备中想出来。

判断标准：当你能对着一个币的数据说出「我不碰，因为 X 规则」——你就够了。不是看透本质，是**能给出拒绝的理由**。

做不到这一句话，再准备一万年也是拖延。

## 小结

1. 六个行为模型中，首买时间窗和卖出同步性最实用——时间戳不会骗人，同步性最难伪装。
2. 数学工具优先上 HHI 和 Z-Score，半天搞定，立刻能用。
3. 字段反推四问（量什么 / 能伪 / 能算 / 本质）是碰每个字段之前的必经动作。
4. 不可伪造的链上事实是一切分析的地基。可伪造的指标只能做参考。
5. 思维准备的终点不是「看透本质」，是「能给出拒绝的理由」。够了就动手。
