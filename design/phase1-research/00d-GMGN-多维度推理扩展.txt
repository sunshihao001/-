GMGN 字节组合 — 多维度推理扩展
====================================
核心观点：230 字节是「原材料」，你从什么角度问它，它就产出什么推理。
====================================

我们已经完成的维度（1 个）：
  市场结构状态 → 37 L1 + 16 L2（SM积累/出货/操纵/生命周期...）

以下 4 个新维度，用同样的 230 字节，换一个问题框架，
可以推导出完全不同的 L1/L2 组合。

============================================================
维度二：钱包层面推理
============================================================

核心问题：不是「市场在做什么」，而是「谁在做什么、为什么、下一步可能做什么」。

这不需要新字段——用现有的 token holders / token traders 的
每钱包数据，换一种聚合方式。

---

推理方向 1：钱包角色演化
-------------------------
问题：一个钱包从进入 token 到现在的行为轨迹是什么？

可用字节（per wallet）：
  start_holding_at     → 什么时候进来的
  buy_volume_cur       → 累计买了多少
  sell_volume_cur      → 累计卖了多少
  sell_amount_percentage → 卖出了持仓的多少
  last_active_timestamp → 最近还在操作吗
  realized_profit      → 已经赚了多少
  unrealized_profit    → 账面还有多少

L1 派生（钱包级）：
  holding_duration = now - start_holding_at
    短（<5min）+ 高 sell_amount → sniper 已离场
    长（>2h）+ 低 sell_amount  → 长期持有者
  exit_speed = sell_amount_percentage / holding_duration
    快出 → 短线交易者
    慢出 → 逐步减仓
  profit_per_minute = realized_profit / holding_duration
    高 → 高效交易者（可能是专业 sniper）

L2 结构（钱包群体级）：
  - 钱包角色分布：sniper/短线/中线/长期 各占多少
  - 角色迁移：昨天是 sniper 的钱包今天变成 holder 了
  - 盈利分布：哪个角色群体在赚钱（sniper 全赚 holder 全亏 = 典型 rug）

---

推理方向 2：钱包聚类（行为相似度）
-----------------------------------
问题：不看 GMGN 的标签（smart_degen/renowned），
      只看行为，哪些钱包是一伙的？

可用字节：
  native_transfer.address → 资金来源
  buy_tx_count_cur / sell_tx_count_cur → 交易频率
  avg_cost → 建仓成本区
  start_holding_at → 入场时间窗口

L1 派生（同源/同行为检测）：
  funding_source_cluster = 相同 native_transfer 的钱包群
  cost_basis_cluster = avg_cost 在 ±5% 以内的钱包群
  entry_time_cluster = start_holding_at 在 ±2min 以内的钱包群

L2 结构：
  - 三重合（同源 + 同成本 + 同时间）= 极高概率同一实体
  - 同源但不同时间 → 可能是同一个庄家分批建仓
  - 不同源但同时间 → 可能是 sniper bot 群

---

推理方向 3：SM 钱包质量分层
----------------------------
问题：GMGN 把所有 smart_degen 标成同一类。
      但 SM 之间也有巨大差异。

可用字节（per SM）：
  total_profit（跨 token 的）→ 这个 SM 到底赚了多少
  win_rate（跨 token 的）   → 胜率
  avg_holding_time          → 平均持有时间
  tags 中的其他信息

L1 派生：
  sm_rank = f(total_profit, win_rate, avg_holding_time)
    A 级 SM：高盈利 + 高胜率 + 中长持有 → 真正聪明钱
    B 级 SM：中盈利 + 中胜率 → 普通专业交易者
    C 级 SM：低盈利/新标记 → 标签可能不准确

L2 结构：
  A 级 SM 积累 → 强信号（比泛 SM 积累可信得多）
  C 级 SM 积累 → 弱信号（可能是运气好被 GMGN 标上）
  A 级 SM 出货 + C 级 SM 接盘 → 顶部信号

============================================================
维度三：市场微结构推理
============================================================

核心问题：不是「价格在涨还是跌」，而是「价格是怎么被推动的、
         每一步的微观机制是什么」。

这需要比当前 1h 窗口更细的粒度——用 kline 的 1m 数据。

---

推理方向 1：量价关系微观分析
-----------------------------
问题：每一根 1m K 线的量和价的关系是什么？

可用字节（per 1m kline）：
  open, high, low, close, volume, amount

L1 派生：
  每根 K 线的：
    price_change = close - open
    volume_intensity_micro = volume / avg_volume_last_10
    buy_pressure = (close - low) / (high - low)
      接近 1 → 买方在收高（买压）
      接近 0 → 卖方在压低（卖压）

L2 结构（连续 N 根 K 线）：
  - 放量阳线连续 → 真实买盘推动
  - 缩量阳线连续 → 无阻力上涨（可能是庄家控盘）
  - 放量阴线连续 → 真实抛压
  - 放量但价格不动 → 有人在吸筹或出货（看后续方向）

---

推理方向 2：价格冲击估算
-------------------------
问题：一笔买入会推动价格多少？

可用字节：
  liquidity → 池子深度
  volume_per_swap → 当前平均交易大小
  buy_volume_1h / price_change_1h → 历史价格冲击

L1 派生：
  impact_estimate = expected_slippage_for_size(size, liquidity)
    卖 $500 在 $50k 池子 → 约 1% 滑点
    卖 $500 在 $5k 池子 → 约 10%+ 滑点

L2 结构：
  - 低冲击市场（> $100k liquidity）→ 可以正常交易
  - 中冲击市场（$10k-$100k）→ 只能小额
  - 高冲击市场（< $10k）→ 无法退出 → L2-C3

---

推理方向 3：订单流不平衡
-------------------------
问题：从连续的 buy/sell 序列能看出什么？

（需要比 GMGN 更细的 trade 数据，GMGN 只给了聚合的 buys/sells 笔数。
 但如果有 kline 的 1m 数据，可以用 volume + price direction 近似）

L1 派生（需要 trade 级数据或高频 kline）：
  trade_flow_sequence = [+100, -50, +200, -30, ...]
  cumulative_delta = 累计买入量 - 累计卖出量

L2 结构：
  - cumulative_delta 持续上升 + 价格上涨 → 健康上涨
  - cumulative_delta 持续上升 + 价格不涨 → 有人在吸筹
  - cumulative_delta 转负 + 价格横盘 → 吸筹完成准备拉升 or 放弃

============================================================
维度四：庄家/做市商生命周期
============================================================

核心问题：不是「有没有操纵」，而是「操纵者现在处于什么阶段」。

这个维度直接回答你最开始的「反向推理策略」需求——
从字节反推庄家的行为模式。

---

推理方向 1：庄家吸筹阶段检测
-----------------------------
特征：价格低位横盘 + 量在放大但价格不涨 + SM 不参与（庄家匿名钱包）

可用字节：
  price_change_percent1h near 0（价格不动）
  volume_momentum > 1.5（量在放大）
  buy_dominance > 0.5（买盘偏多）
  smart_degen_count = 0（SM 还没注意到）
  top_10_holder_rate rising（筹码在集中）
  wallet_source_convergence 高（同源钱包在收集）

L2 候选：COVERT_ACCUMULATION（暗中吸筹）
  含义：有人在系统性地收集筹码，但还没拉盘
  下一步：等吸筹完毕 → 进入拉盘阶段

---

推理方向 2：庄家拉盘阶段检测
-----------------------------
特征：价格快速上涨 + 量暴增 + 新人涌入 + SM 开始注意到

可用字节：
  price_change_percent1h > 50%
  volume_momentum > 3.0
  fresh_wallet_ratio > 0.6
  smart_degen_count 从 0 变成 > 0（SM 开始进场）

L2 候选：PUMP_IN_PROGRESS（拉盘中）
  含义：庄家正在拉盘吸引关注
  下一步：等新人涌入足够 → 进入出货阶段

---

推理方向 3：庄家出货阶段检测
-----------------------------
特征：价格还在高位但 SM 开始卖 + 新人大量接盘 + 庄家钱包在分散出货

可用字节：
  sm_direction_signal 偏卖
  sm_exit_ratio 上升
  fresh_wallet_ratio 极高（新人在接）
  wallet_source_convergence 高（同源钱包在分散减仓）
  top_10_holder_rate 开始下降（庄家在分散筹码）

L2 候选：DISTRIBUTION_PHASE（出货中）
  这是我们已有的 L2-B1 + L2-B2 的组合深化

---

推理方向 4：庄家离场后
-----------------------
特征：价格自由落体 + 量萎缩 + 所有大仓已走

L2 候选：ABANDONED（已被抛弃）
  区别于 L2-D2（自然死亡）：ABANDONED 有清晰的庄家生命周期痕迹
  共同点：都不值得再研究

---

庄家生命周期完整链条：
  吸筹 → 拉盘 → 出货 → 离场 → 归零/CTO
  每个阶段在 GMGN 字节中留下不同的痕迹组合

============================================================
维度五：策略类型推理
============================================================

核心问题：不是「现在什么结构」，而是「什么样的交易策略
         在当前的字节组合中能找到机会」。

---

推理方向 1：动量策略适配
-------------------------
需要的字节特征：
  volume_momentum > 2.0（强动量）
  price_change_percent1h 持续同向
  sm_direction_signal 同向
  liquidity 足够大（可以进出）
  mcap_to_liquidity_ratio < 20

L2 产出：MOMENTUM_FAVORABLE
  含义：当前市场处于动量友好的环境
  但不代表「应该追」——只是说「动量策略的客观条件成立」

---

推理方向 2：均值回归策略适配
-----------------------------
需要的字节特征：
  price_to_ath_ratio < 0.3（深度回调）
  buy_dominance 开始转正
  sm_direction_signal 偏买
  insider_activity_composite < 0.3（无操纵干扰）

L2 产出：MEAN_REVERSION_FAVORABLE
  含义：当前存在均值回归的客观条件
  风险：Memecoin 可能直接从 -90% 到 -99%（无回归）

---

推理方向 3：事件驱动策略适配
-----------------------------
需要的字节特征：
  cto_flag = 1 + cto_quality > 0.6
  或者 launchpad_progress > 0.9（即将毕业）
  或者 dex_marketing_intensity >= 3（大营销事件）

L2 产出：EVENT_DRIVEN_OPPORTUNITY
  含义：存在事件催化剂
  风险：事件结果不确定

---

推理方向 4：狙击策略适配
-------------------------
需要的字节特征：
  token_age_minutes < 2（极早期）
  is_on_curve = true
  launchpad_progress > 0.8（快毕业了）
  sniper_count 还不高（竞争少）

L2 产出：SNIPE_OPPORTUNITY
  含义：存在开盘狙击机会
  风险：极高，90%+ 的 snipe 亏损

每个维度用同一套字节，换一个问题框架，产出完全不同的推理结构。

============================================================
核心方法论：
============================================================

  「字节是固定的，维度是无限的。」
  
  不是「这 230 个字节能做什么」，
  而是「我想理解市场的哪个切面 → 这个切面在交易中会留下什么痕迹 →
  GMGN 字节里能不能看到 → 怎么组合才能把那个切面还原出来」。

  每换一个「我想理解什么」，就诞生一个新维度。
