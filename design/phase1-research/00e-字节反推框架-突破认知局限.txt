从字节本身反推框架 —— 突破个人认知局限的方法
============================================================
核心问题：外部框架（VWAP/庄家生命周期/策略类型）来自个人经验。
          个人经验有天花板。怎样让字节自己告诉我我不知道的东西？

原则：不预设框架，只预设「组合规则」，让字节的组合结果反推框架。

============================================================
方法一：全字段穷举配对
============================================================

GMGN 230 个字段中，约 80 个是数值型字段。
任意两个配对 → 80×79/2 = 3,160 种可能的比值/乘积/差值。

大部分配对无意义。但有意义的配对中：
- 60-70% 你会直觉想到（buy_volume/sell_volume = buy_dominance）
- 20-30% 你不直觉但推理后能理解（sm_count/top10_rate = 单位集中度SM密度）
- 5-10% 你完全想不到——这些就是认知边界外的发现

操作：
  列出所有数值型字段
  → 对每一对计算 A/B, A×B, A-B
  → 对每个结果问「这个值如果异常大或异常小，在真实市场中对应什么？」
  → 用历史 token 数据验证（找几个你知道结果的 token 对比）
  → 如果出现「这个值异常 + 但你不理解为什么」→ 就是新发现

============================================================
方法二：异常驱动发现
============================================================

不先想「我要找什么框架」。
先问「这个 token 和同类的比，哪里不对劲？」

操作：
  取 10 个已知 SM 赚钱的 token → 计算所有 L1 feature
  取 10 个已知 SM 亏钱的 token → 计算所有 L1 feature
  → 对比：哪个 feature 在两个群体间差异最显著
  → 如果差异最大的 feature 不在你现有框架里 → 新发现

  同样的方法用于：
    已知 rug 的 token vs 已知正常毕业的 token
    已知 CTO 成功的 token vs 已知 CTO 失败的 token
    已知庄家吸筹后拉升的 token vs 已知庄家吸筹后放弃的 token

  你不是在验证「SM 赚钱的 token 有什么特征」。
  你是在问「有什么特征是我完全没想过、但数据告诉我很重要的」。

============================================================
方法三：无标签模式聚类
============================================================

不预设「SM 积累」「庄家出货」这些标签。
让 token 按字节特征的相似度自己分组。

操作：
  取 100 个 token，对每个计算 37 个 L1 feature
  → 聚类（不需要你知道 cluster 叫什么）
  → 对每个 cluster，反向看：
      这些 token 有什么共同特征？
      它们后来的价格走势有什么规律？
      有没有 cluster 是你现有框架完全无法描述的？

  例子：
    你可能发现一个 cluster：
      sm_penetration 中等 + volume_intensity 极高 +
      insider_activity 中等 + price_change 不温不火
    → 这个 cluster 的属性你现有框架里没有对应的名字
    → 回溯这些 token 后来发生了什么
    → 如果它们全部在 2h 内 rug → 新框架：「伪装积累型 rug」
    → 如果它们全部在 24h 内涨 10x → 新框架：「隐蔽爆发」

============================================================
方法四：对立框架生成
============================================================

对每一个你已有的框架，强行构建它的对立面。

操作：
  现有框架：SM 积累 → 看涨
  对立问题：什么条件下 SM 积累 = 看跌？
  → 回溯历史：有没有 token 里 SM 积累但最终暴跌的？
  → 找这些 token 的共同字节特征
  → 可能发现：SM 积累 + SM 平均持仓时间极短 +
             SM 在多个 token 同时积累 = 短线 sniper 行为 ≠ 看好
  → 新框架：「SM 短线轮动」vs「SM 长期建仓」

  现有框架：Dev 清仓 → 好信号
  对立问题：Dev 清仓什么时候反而是坏信号？
  → 可能发现：Dev 清仓 + 没有 SM 接盘 + 社群消失 = 放弃
  → 新框架：「Dev 离场 ≠ CTO，也可能是彻底抛弃」

============================================================
方法五：时间序列挖掘
============================================================

现有框架几乎全是基于单时间点快照。
如果你有同一 token 的多个时间点数据，字节的变化轨迹会暴露新框架。

操作：
  每 5 分钟采样一次，持续 2 小时 → 24 个时间点
  对每个 L1 feature 画变化曲线
  → 看曲线的形状：
    单调上升型 → 趋势
    先升后降型 → 冲高回落
    忽升忽降型 → 操纵/刷量
    先降后升型 → 超跌反弹
  → 有没有你现有框架无法解释的曲线形状？
  → 如果有 → 找多个 token 验证这种curve和后市的关系 → 新框架

============================================================
方法六：跨链对比
============================================================

同样的字节，在 Solana meme 和 BSC meme 和 ETH 上含义不同。
对比差异 → 发现 Solana 独有的规律。

操作：
  取 Solana 上的 50 个 token → 计算 L1/L2
  取 BSC 上的 50 个 token → 计算 L1/L2
  → 同样的 SM 积累模式，在 Solana 和 BSC 上后续走势一样吗？
  → 如果不一样 → 差异在哪里 → 是什么造成的？
  → 可能是 Solana 独有的「pump.fun 毕业效应」「Raydium 池结构」
  → 新框架：跨链不可直接套用，需要链级修正

============================================================
总结：从「套框架」到「生框架」
============================================================

套框架：你知道庄家有生命周期 → 去找字节支撑这个生命周期
        → 能找到，但找不到你不知道的东西

生框架：你不知道有什么 → 让字节的数学关系自己暴露规律
        → 穷举配对、异常检测、聚类、对立生成、时间序列、跨链对比

操作顺序建议：
  1. 先做完「套框架」（你已有的 37 L1 + 16 L2）
  2. 用以上 6 个方法逐个探索
  3. 每次发现一个现有框架无法解释的模式 → 命名 → 就是新框架
  4. 新框架积累多了 → 你的认知边界就扩展了
