    55|## 3. grill-with-docs 的工作方式
    56|
    57|主 agent 作为 interviewer，一次只问一个高价值问题。
    58|
    59|每个问题必须用于确定以下之一：
    60|
    61|```text
    62|目标
    63|边界
    64|输入
    65|输出
    66|状态机
    67|阻断条件
    68|下游交接
    69|验证方式
    70|```
    71|
    72|不能问泛问题，例如：
    73|
    74|```text
    75|你觉得还要不要继续？
    76|你想做成什么样？
    77|还有什么补充？
    78|```
    79|
    80|要问能冻结成文档的问题。

    84|## 4. 本项目的核心前提
    85|
    86|后续 agent 必须先接受：
    87|
    88|```text
    89|1. 本项目不是找庄家。
    90|2. 本项目不是找买点。
    91|3. 本项目不是 live trading。
    92|4. 本项目是状态机系统。
    93|5. 核心输出是 EXCLUDE / RECORD_ONLY / WATCHING / RISK_MONITOR / PAPER_READY / REVIEW_REQUIRED。
    94|6. 安全和市场硬风险是乘法门禁。
    95|7. 钱包结构解决筹码控制权问题，不解决入场时机问题。
    96|8. K 线策略解决纸面参与位置问题，不替代钱包结构判断。
    97|9. PAPER_READY 只允许纸面验证，不允许真实交易。
    98|10. 所有复盘要看判断链哪里错了，而不是只看盈亏。
    99|```
